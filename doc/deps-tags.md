# FSPlayer 依赖库明细

数据来源：各版本 `.github/workflows/apple.yml` install 的库（`ass` + `ffmpeg`/`ffmpeg8`），
通过实际执行 `main.sh install` 后观察 `build/product/<plat>/universal/` 解压出的目录，确认每个预编译包捆绑的依赖库，再从对应 FFToolChain commit 的 `configs/libs/` 读取各平台 PRE\_COMPILE\_TAG。

说明：

- 三平台（iOS/macOS/tvOS）tag 相同时合并为一列，有差异时分别列出
- 1.0.0 \~ 1.0.2 早期各平台编译时间戳不同，1.0.3 起统一
